P0

Warm lexical brain

DONE

One SQLite file (FTS5) behind a SearchIndex trait — BM25 with first-class per-column weights + weighted RRF fusion (filename match outranks a body-only mention), an ignore-aware walk, the secrets-redaction hard gate, and a GUI-resident worker thread that fails open. Backed by an offline sandbox proof and a discriminating relevance benchmark.

P1

Native memory + doctor

DONE

Structured memory notes (YAML-frontmatter scan over .koden-memory/) plus a recursive incremental watcher, and a deterministic "doctor" that emits findings into a human-gated proposal queue. The Librarian proposes — it never auto-edits user files.

notes table proposal queue · reject-sticky review inbox UI
P2

AST graph

DONE

tree-sitter (Rust + TS/TSX) drives definition/import extraction into resolved file→file edges and a tiered code-impact closure. Edges rebuild as a pure function of (imports, file set), so incremental indexing provably converges with a full rebuild — gate proven against ADD+DELETE+RENAME+MODIFY.

tree-sitter code_nodes · code_edges incremental == full rebuild
P3

Cache-stable gist

DONE

A token-bounded, fingerprint-keyed context bundle injected into agents as the prompt-cache-stable prefix. Built over one pinned DB snapshot so it is byte-identical on an unchanged relaunch (the prompt-cache gate) — hardened against a torn-snapshot read that would have split the key across two states.

blake3 cache key byte-identical relaunch single-snapshot read launcher-prepended
P4

Budgeted reflect + crash-resume

DONE

The only token-spending path: a crash-safe spend ledger (reserve → call → reconcile — a crash over-counts, never leaks free spend) plus a faithful Conductr "reflect" port behind a fake-LLM seam. Adds per-pane crash-resume journals (Tier-1) and a Tier-2 claude --resume plan. Deterministic core; the GUI half is the live-evidence pass.

spend ledger metadata-only digest redact before cloud resume journals
P5

Deferred semantic seams

DONE

Embedder/VectorStore traits + an embedderId header behind a DEFAULT-OFF semantic cargo feature — absent from the shipped binary. The shape that lets semantic slot in later with zero schema churn; a dependency-free reference impl keeps the gated code from bit-rotting under CI.

feature off by default no vector leg in v1 zero schema churn to enable

V2.2

Ranking-quality calibration

DONE

Turned GUESSED BM25/RRF weights into MEASURED ones with a discriminating benchmark — confuser pairs (target only in path, distractor only in body) plus MRR / precision@1 and a leak-gated calibration sweep. Result: strict identity-dominant weighting is optimal; the "provisional" comment became "measured" — after the panel caught two false "measured" claims and they were corrected.

How every phase shipped

One cadence, repeated: build → an adversarial verification fan-out by a separate set of agents → harden → commit on green. Across the build those fan-outs (~30+ agent-reviews) caught REAL defects, not rubber-stamps — each fixed before its phase closed:

  • a money-path under-charge (a 2xx with 0/0 usage charged $0);
  • two secret leaks to the cloud (note anchors + interpolated doctor detail);
  • a crash-resume torn-snapshot that split the gist cache key across two states;
  • a supersession-direction under-detection that yielded zero candidates on a correct corpus;
  • false "measured" benchmark claims (a wrong file count and a >= that should have been a strict >).
Current gates: clippy -D warnings clean · ~297 lib tests + 34 integration + benchmark · schema v9 · main untouched.
